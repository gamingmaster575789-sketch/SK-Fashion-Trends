
# SK Fashion Trends

A fashion e-commerce website developed as a B.Sc. Computer Science mini project.

## Technologies Used
- HTML
- CSS
- JavaScript
- Bootstrap
- Python Flask
- SQLite

## Features
- User registration and login
- Browse and search fashion products
- Product details and categories
- Shopping cart
- Order-related functionality
- Admin product management

## Project Purpose
The project demonstrates web development, backend programming, database integration, and basic e-commerce workflows.

## Future Enhancements
- Online payment integration
- Wishlist
- Improved inventory management
- Product recommendations
